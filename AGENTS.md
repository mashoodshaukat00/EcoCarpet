# AGENTS.md

## Cursor Cloud specific instructions

### Overview

EcoCarpet is a subscription-based carpet rental e-commerce platform with:
- **Backend**: ASP.NET Core 8.0 Web API at `http://localhost:5255` (HTTP profile)
- **Frontend**: React 18 + Vite 6 + TailwindCSS 4 at `https://localhost:47592`
- **Database**: SQL Server 2022 via Docker on port 1433 (SA password: `EcoCarpet123!`, database: `EcoCarpetDB`)

### Prerequisites (already installed by environment setup)

- .NET 8 SDK at `/usr/local/share/dotnet`
- Docker with SQL Server container (`mssql`)
- Node.js 22+ and npm
- `dotnet-ef` global tool

### Environment variables

These must be set in the shell (already in `~/.bashrc`):
```
export DOTNET_ROOT=/usr/local/share/dotnet
export PATH="$PATH:/home/ubuntu/.dotnet/tools"
```

### Starting services

1. **Docker + SQL Server**: `sudo dockerd &` then `sudo docker start mssql` (if container exists) or create with:
   ```
   sudo docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=EcoCarpet123!" -p 1433:1433 --name mssql -d mcr.microsoft.com/mssql/server:2022-latest
   ```
2. **Backend** (from `EcoCarpet/EcoCarpet.Server/`): `dotnet run --launch-profile http`
   - The SPA proxy auto-starts the Vite frontend dev server
   - Swagger UI: `http://localhost:5255/swagger`
3. **Frontend standalone** (from `EcoCarpet/ecocarpet.client/`): `npm run dev`

### Key gotchas

- `appsettings.json` is gitignored and must be created in `EcoCarpet/EcoCarpet.Server/` with the SQL Server connection string (see README for format).
- The frontend `.env` file must define `VITE_API_URL=http://localhost:5255/api`.
- The Vite config (`vite.config.js`) requires HTTPS dev certs generated by `dotnet dev-certs https`. These are auto-generated on first `npm run dev` if `dotnet` is in PATH.
- CORS is configured to allow `https://localhost:47592` only.
- After a fresh database, seed data via: `POST http://localhost:5255/api/subscriptions/seed` and `POST http://localhost:5255/api/Carpet/seed`.
- EF Core migrations: `dotnet ef database update` (from the Server project directory).

### Lint / Test / Build

- **Frontend lint**: `npm run lint` (from `ecocarpet.client/`)
- **Frontend build**: `npm run build` (from `ecocarpet.client/`)
- **Backend build**: `dotnet build` (from `EcoCarpet.Server/`)
- No automated test suites exist in this repository.
